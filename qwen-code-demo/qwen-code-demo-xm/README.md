# 贴心小秘书

一个结合高德地图API的智能情绪感知应用，为用户提供情绪安慰和贴心出行推荐。

## 功能特点

1. **情绪感知与安慰** - 通过自然语言处理识别用户情绪，并提供温暖的安慰话语
2. **贴心出行推荐** - 根据用户情绪和位置，推荐合适的地点（书店、咖啡馆、餐厅等）
3. **情绪化路线规划** - 生成专属治愈路线，帮助用户改善心情
4. **小确幸惊喜模式** - 为用户生成个性化惊喜计划

## 技术栈

- HTML5 + CSS3 + JavaScript (ES6+)
- 高德地图JavaScript API
- 响应式设计
- 模块化JavaScript

## 如何使用

1. 克隆或下载本项目到本地
2. 注册高德地图开发者账号并获取API密钥
3. 在`gaode-api.js`文件中替换`YOUR_GAODE_API_KEY_HERE`为你的实际API密钥
4. 使用现代浏览器打开`index.html`即可使用

## 功能详解

### 情绪感知与安慰
用户可以输入任何描述心情的文字，系统会自动识别情绪并提供温暖的安慰话语。

### 出行推荐
系统会根据用户情绪推荐不同类型的地点：
- 心情低落：推荐安静的书店、咖啡馆、公园等
- 想庆祝：推荐浪漫餐厅、夜景观景台等
- 想犒劳自己：推荐购物中心、美食广场、SPA等

### 路线规划
根据用户情绪生成专属路线，例如：
- 治愈路线：咖啡馆 → 书店 → 公园 → 甜品店
- 庆祝路线：精品餐厅 → 艺术展览 → 观景台 → 音乐会
- 犒赏路线：网红餐厅 → 购物中心 → 电影院 → KTV

### 惊喜模式
为不同情绪提供个性化惊喜计划，帮助用户创造美好回忆。
