# 贴心小秘书 💖

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Platform](https://img.shields.io/badge/platform-web-lightgrey)](https://github.com/your-username/mood-companion)

一个基于地理位置和情绪识别的贴心陪伴应用，为您提供个性化的关怀和推荐。

## 🌟 项目亮点

* **智能情绪识别**: 通过自然语言处理技术理解您的情绪状态
* **个性化推荐**: 结合地理位置和心情，智能推荐适合的场所
* **情感路线规划**: 为您定制专属的情绪调节路线
* **暖心小惊喜**: 随机生成温馨的惊喜计划
* **情绪日记**: 记录和回顾您的情感历程
* **可视化地图**: 直观展示推荐地点和路线规划

## 🚀 功能特色

### 📍 地理位置服务
- 自动获取当前位置信息
- 手动位置输入备选方案
- 集成高德地图API实现精准定位

### 💭 情绪识别与关怀
- 实时情绪分析
- 个性化安慰语生成
- 情绪变化趋势跟踪

### 🎯 智能推荐系统
- 基于情绪状态的场所推荐
- 评分和营业时间信息展示
- 推荐地点历史记录

### 🛣️ 路线规划
- 多地点情绪调节路线
- 详细导航信息展示
- 最优路径智能计算

### 🎁 惊喜计划
- 随机生成温馨惊喜方案
- 多种主题惊喜选择
- 个性化惊喜定制

### 📔 情绪日记
- 情绪记录和回顾
- 时间轴展示功能
- 情感变化分析

## 🛠 技术栈

- **前端技术**: HTML5, CSS3, JavaScript (ES6+)
- **地图服务**: 高德地图API
- **UI设计**: 
  - 响应式布局设计
  - 渐变色彩搭配
  - 卡片式组件设计
  - 动画效果增强用户体验
- **核心功能**:
  - Geolocation API 实现定位
  - DOM操作实现交互
  - 异步编程处理用户操作

## 📦 安装与使用

1. 克隆项目到本地：
```bash
git clone https://github.com/your-username/mood-companion.git
```

2. 进入项目目录：
```bash
cd mood-companion
```

3. 使用浏览器打开 `index.html` 文件即可使用

## 🔧 开发指南

### 项目结构
```
mood-companion/
├── index.html          # 主页面
├── styles.css          # 样式文件
├── script.js           # 核心逻辑
└── README.md           # 项目说明
```

### 核心模块

1. **地理位置模块**
   - 实现定位功能
   - 处理定位异常情况
   - 地图初始化和展示

2. **情绪识别模块**
   - 情绪关键词识别
   - 安慰语生成算法
   - 情绪日记管理

3. **推荐系统模块**
   - 推荐算法实现
   - 推荐卡片渲染
   - 推荐地点标记

4. **路线规划模块**
   - 路线生成算法
   - 路线展示界面
   - 导航功能集成
